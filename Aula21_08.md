# Resumo — Predição, Previsão e Recomendação

- **Predição:** utiliza dados atuais para **classificar ou categorizar** algo.
  - Exemplo: identificar se um professor é **bom ou não**.
  - Usa dados de entrada (**X**) para gerar uma classificação (**Y**).
  - O treinamento deve utilizar **amostras reais**.

- **Previsão:** trabalha com o **futuro**, usando séries temporais, estatística e probabilidade.
  - Exemplo: prever resultados futuros com base em dados históricos.

- **Base de dados:** tanto a predição quanto a previsão precisam de uma **base de dados robusta**, com uma quantidade consistente de dados.

- **Recomendação:** utiliza os resultados da predição ou previsão para **sugerir ações**, como medicamentos ou tratamentos.

- # Comparativo de Modelos de Predição

Este documento apresenta uma análise comparativa de diferentes técnicas de Machine Learning utilizadas para tarefas de predição e previsão. O material é voltado para a prática, focando na implementação e na avaliação de performance.

## Objetivos Principais
- Implementar diversos modelos de aprendizado de máquina para comparação.
- Avaliar a performance dos modelos através de métricas de erro.
- Prover um guia prático para escolha do melhor modelo para um conjunto de dados específico.

## Estrutura Típica do Conteúdo
O material geralmente abrange os seguintes tópicos:

1. **Preparação dos Dados**: Pré-processamento e limpeza necessários para que os algoritmos de predição funcionem corretamente.
2. **Modelos Abordados**:
   - **Regressão Linear**: Para modelagem básica de relações lineares.
   - **Árvores de Decisão**: Para capturar relações não-lineares.
   - **Random Forest**: Método de ensemble para aumentar a precisão e reduzir o sobreajuste (*overfitting*).
   - **Modelos de Séries Temporais**: Técnicas específicas baseadas em janelas temporais.
3. **Avaliação de Performance**:
   - Uso de métricas como **MAE** (Mean Absolute Error), **MSE** (Mean Squared Error) e **R²** (Coeficiente de Determinação).
4. **Conclusão**: Comparação final entre os resultados obtidos por cada modelo.

## Considerações Práticas
O foco deste material está no fluxo de trabalho de *Data Science*: importar bibliotecas (como `scikit-learn`, `pandas`, `numpy`), treinar modelos, prever valores e gerar gráficos comparativos de desempenho.
